# Пиксель-Данк: Дуэль на одном экране

2D HTML5 аркада про баскетбольные дуэли 1v1 для публикации на Яндекс.Игры.

## Что реализовано

- Режимы: **Соло против бота** (3 сложности) и **Два игрока на одном устройстве**.
- Матч с таймером, счётом, экраном результатов и реваншем.
- Экранная структура: главное меню, выбор режима, выбор сложности, скины, настройки, как играть, правовая информация.
- Десктоп и мобильное управление (две панели управления на экране).
- Базовая интеграция жизненного цикла Яндекс Игр:
  - `LoadingAPI.ready()` вызывается при первой интерактивной сцене меню.
  - обработка `game_api_pause` / `game_api_resume`.
- Метаданные безопасных оригинальных скинов:
  - `assets/metadata/characters.json`
  - `assets/metadata/characters.csv`

## Быстрый запуск

1. Откройте `index.html` в браузере.
2. Нажмите **Играть** и выберите режим.
3. Забросьте больше мячей за 75 секунд.

## Управление

### Игрок 1 (ПК)
- Движение: `A / D`
- Прыжок: `W`
- Бросок: `S` или `F`

### Игрок 2 (ПК)
- Движение: `← / →`
- Прыжок: `↑`
- Бросок: `↓` или `L`

### Мобильные
- Левая панель: Игрок 1 (джойстик + прыжок/бросок)
- Правая панель: Игрок 2 (джойстик + прыжок/бросок)

## Интеграция SDK Яндекс Игр

В прод-сборке подключите SDK перед `game.js`:

```html
<script src="/sdk.js"></script>
<script src="game.js"></script>
```

### Где вызывать `ready`

`LoadingAPI.ready()` вызывается в `game.js` в момент открытия интерактивного меню (`showScreen()` -> `callGameReady()`). Перед этим проект пытается инициализировать SDK через `YaGames.init()`.

### Пауза/возобновление

Подписки на `game_api_pause` и `game_api_resume` стоят в `initYandexSdkHooks()`. На pause ставится флаг `yandexPaused` и останавливается `GameplayAPI`; на resume игра корректно возобновляется.

### Реклама и покупки

- Показы interstitial/rewarded вставляются в логических паузах (между матчами, на экране результатов).
- Покупки должны использовать только API SDK Яндекс Игр.

## Структура файлов

- `index.html` — экраны UI и canvas.
- `styles.css` — пиксельно-мультяшный адаптивный интерфейс.
- `game.js` — игровой цикл, режимы, бот, физика мяча, хуки SDK.
- `assets/metadata/characters.json` — полный набор из 20 оригинальных скинов.
- `assets/metadata/characters.csv` — CSV-версия метаданных.
